The portrait is committed directly in this repository, and every data graphic<br>
is generated here too. The scheduled [GitHub Action](.github/workflows/stats.yml)<br>
reads GitHub's GraphQL API with the built-in workflow token, draws these SVGs,<br>
and commits only when pixels change.

The illustrated portrait is derived from my profile photo and loads locally from<br>
this repository—no avatar-server request at view time. The charts reveal with<br>
SMIL inside each SVG, so there is no JavaScript and no third-party widget to<br>
rate-limit.

JetBrains Mono is subset by role, licensed under the SIL OFL 1.1, and embedded<br>
inside every data SVG. That keeps chart geometry identical on every platform<br>
and makes the page fully self-contained.
