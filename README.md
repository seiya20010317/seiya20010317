Every graphic on this page is generated inside this repository. The scheduled<br>
[GitHub Action](.github/workflows/stats.yml) reads GitHub's GraphQL API with the<br>
built-in workflow token, draws these SVGs, and commits only when pixels change.

The rotating globe is generated by<br>
[`scripts/generate_globe.py`](scripts/generate_globe.py). Its world strip wraps<br>
continuously inside a clipped sphere, with a moving satellite, atmosphere pulse,<br>
and twinkling stars—all SMIL inside the SVG. The charts use the same native<br>
animation system, so there is no JavaScript and no third-party widget to rate-limit.

JetBrains Mono is subset by role, licensed under the SIL OFL 1.1, and embedded<br>
inside every image. That keeps the typography identical on every platform and<br>
makes the page fully self-contained.
